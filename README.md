# 轨道使命 / Orbit Mission

包名 `com.example.orbitmission`。Kotlin、Compose SpatialUI、自绘航天仪表界面、PICO Spatial SDK 6.1.9 原生 ECS 三维场景。包含太阳、八大行星、长征风格载人火箭、引力飞行、实时遥测、任务判定、操作引导和三语设置。

## 构建与安装

使用 JDK 17+（本次使用 Android Studio 内置 JBR）、Android SDK 和官方 scaffold 的 Gradle Wrapper。首次在 Android Studio 打开后执行 **Sync Project with Gradle Files**。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
pico-cli app install app/build/outputs/apk/debug/app-debug.apk --device emulator-5554 --replace
pico-cli app launch com.example.orbitmission --device emulator-5554
```

当前版本为 **1.3.2（versionCode 6）**。可安装 APK、源码交付包及效果录屏见 [GitHub Releases](https://github.com/DDDCC5/OrbitMission/releases)。本机构建交付文件位于 `output/OrbitMission-debug.apk`。平台需要 PICO OS 6 / Spatial 运行环境；普通 Android 手机不具备其空间运行服务。

## 操作

- 开场 Logo 保持 5 秒，随后太阳及八大行星依次出现；首次启动显示教程。
- 手柄射线指向行星，确认键选中；支持眼动连续注视 2 秒选择。也提供自绘行星名称控制，方便无眼动设备操作。
- 设置中的“启用眼动”由用户主动发起系统权限申请；设备须支持眼动并完成校准。没有眼动能力时使用手柄。
- 握持键抓取火箭，移动和转动手柄调整发射位置与方向，松开启动。也可直接从默认推荐位置发射。
- 持续按住扳机加速；仪表显示速度、距行星中心距离、合力、飞行时长、偏心率和倒计时。
- 连续稳定环绕一周后成功并继续飞行；碰撞、越界或 90 秒超时失败，可重试或更换行星。设置与应用后台状态会暂停任务。
- 简体中文、繁体中文文字分别提供；两种中文共用 `zh-Hans` 语音，English 使用英文语音。

## 物理和显示约定

计算使用 SI 单位、`G=6.67430e-11`、各天体真实质量和半径、太阳与选中行星的两源引力，采用有界步长 velocity Verlet。行星相对坐标系扣除行星自身受到的太阳加速度；仪表引力显示火箭实际受到的两源矢量合力，火箭质量为 10,000 kg。地球近地表加速度约 9.8 m/s²，其他天体按 `GM/r²` 计算。

这是固定日星间距的限制性近似，不模拟完整太阳系 N 体运动。总览太阳光球半径 0.52 m，八大行星共用相同物理尺度（地球半径约 4.77 mm）；总览间距为交互需要压缩。1.3 版选中后，行星球体统一为初始木星体积的 5 倍，直径约 18.3 cm。线性倍率为立方根换算，太阳半径和日星间距随该行星同比放大；两者仍同高，选中行星位于正前方 2.1 m，太阳向左展开。返回恢复总览的原尺寸、位置和间距。推荐轨道为 1.5 倍行星半径，模拟时间加速使推荐轨道约 30 秒环绕一周，90 秒倒计时使用任务实际经过时间。自转保持真实周期比例和顺逆方向，统一采用 3600 倍可视时间速度。轨道“高度”按需求显示距目标中心距离，而非海拔。

## 验证和文件

- `app/src/test`：物理、状态机、输入仲裁、归一化体积/同比缩放/复位、眼动轨道吸附、语言与偏好单元测试，共 38 项业务测试及 1 项模板测试。
- `app/src/androidTest`：原生 Stage 端到端任务测试，驱动正常 ViewModel 操作并等待真实场景时钟和物理积分完成一圈；不替代实体手柄与眼动验证。
- `reports`：本地环境 doctor、构建、测试、资源和运行证据；公开仓库及源码交付包不包含原始日志和头显截图。验证说明见 [docs/VALIDATION.md](docs/VALIDATION.md)。
- `output/pair-*.png` 和 `output/pair-translation.mp4`：当前版本原生模拟器截图及选择/返回录屏。当前模拟器不支持 CLI 的 `--spatial` 截图参数，因此采用设备显示捕获。
- `ASSET_REVIEW.md`：已确认素材、来源、许可及 Editor 服务失败的记录。太阳/行星/土星环贴图来自 Solar System Scope / INOVE，CC BY 4.0，地球合成同源云层；模型与自绘界面在本项目制作。

已在 PICO 6.1 模拟器完成自动任务回归，并安装到连接的 B3110 PICO 头显检查实际画面。实体眼动校准、手柄抓取/扳机和空间音频听感仍需专项实测。源码使用官方 EyeTracking / Controller 与 Spatial Audio API；模拟器无实体手柄时输入提供器可能不可用。

## 1.3 统一选中体积

所有选中行星球体的体积均为初始总览木星的 5 倍，半径为初始木星半径的约 1.71 倍。太阳与日星间距按选中行星的同一线性倍率展开。土星环跟随球体同比缩放，环不计入球体体积。现有平移、原地淡出及恢复总览流程继续沿用，缩放平滑融入其中；返回时复原全部原始尺寸。引力参数及 SI 物理计算不变。

## 1.2 历史选择与复位修复（其保持原尺寸规则已在 1.3 更新）

太阳仅保留原有光球球面，删除所有附加日冕、光点和辉光。选择后太阳和选中行星做 1.2 秒相同位移，其余行星在原地同时淡出；返回时两者退回最初位置，其余行星原地淡入。可在移动中选择返回，运动从当前位置反向衔接。移动期间禁用发射及重选，设置和后台暂停会冻结动画进度。小型类地行星保持真实显示比例，保留较大的不可见射线命中区域和“开始任务”按钮。

## 1.1 历史修复（其日冕及放大任务视图已在 1.2 删除）

Logo/教程距前方 1.15 m；左右仪表前向距离 1.35 m，并分别放大 1.3 倍和 1.2 倍；中间信息前向距离 1.30 m。总览使用太阳及行星真实半径比例，任务视图放大并明确标注。太阳采用 12 组曲线日珥细丝、柔和日冕外晕和沿弧线流动的等离子体光点，替换旧版硬质突起。此为科学形态参考的实时示意效果，不是太阳磁流体仿真。

## 1.3.2 系统语言名称修复

修复 1.3.1 开场仍使用烘焙中英文的旧 Logo 图片的问题。安装入口、开场单一标题和加载名称统一读取系统语言资源：中文系统仅显示「轨道使命」，英文系统仅显示「Orbit Mission」。开场沿用确认的无文字图标，应用内任务语言设置继续独立生效。删除旧双语图片及双语无障碍描述，并显式指定启动 Activity 的本地化名称。新增实体设备 Android 回归测试，覆盖 zh-CN、zh-TW、zh-HK、zh-SG、en-US、en-GB；原生用例 2 项及 JVM 测试 39 项通过。
